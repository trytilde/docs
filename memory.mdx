Memory gives your agent durable context it can recall across conversations and tasks.

Use memory for knowledge that should outlive one session. Keep temporary instructions and request-specific details in the current conversation.

## What belongs in memory

- Stable facts your agent will need again
- Decisions and their supporting context
- Team knowledge shared across workflows
- Summaries of completed work

<Tip>
  Store focused, reusable context. Avoid copying full conversations when a concise summary will do.
</Tip>
