<Steps>
  <Step title="Open Connectors settings">
    In Claude Desktop, go to **Settings**, then click **Connectors**.
  </Step>

  <Step title="Add the Tilde MCP server">
    Click **Add custom connector** and paste the Tilde MCP server URL.

    ```text MCP URL
    https://api.trytilde.ai/mcp
    ```
  </Step>

  <Step title="Authorize in your browser">
    A browser window opens automatically. Sign in to authorize Claude Desktop to access your Tilde account.
  </Step>

  <Step title="Start using Tilde">
    Tilde tools are now available in Claude Desktop.
  </Step>
</Steps>
