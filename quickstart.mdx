<Info>
  Tilde is designed for agents to build more agents. Choose **Agentic workflow** to work through your coding agent, or **For humans** to follow the same steps yourself.
</Info>

This guide builds the [Hello World agent](https://github.com/trytilde/examples/tree/main/hello-world-agent): one signed ChatKit endpoint and one Vercel UI channel using Next.js and the Vercel AI SDK.

<Tabs>
  <Tab title="Agentic workflow">
    <Steps>
      <Step title="Connect your coding agent">
        Connect the client where your coding agent runs to Tilde's global MCP server.

        <Card title="Connect your coding agent" icon="plug" href="/connect-your-agent" horizontal>
          Choose your client and complete its setup.
        </Card>
      </Step>

      <Step title="Ask it to build the example">
        Send this prompt to the connected agent.

        <Prompt description="Build the Hello World agent" icon="sparkles" actions={["copy", "cursor"]}>
Start by reading https://api.trytilde.ai/llms.txt and use https://docs.trytilde.ai/llms.txt to open the production-hosted agent guides. Clone https://github.com/trytilde/examples and use hello-world-agent as the source of truth. Explain the route before changing it, then ask what I want my agent to do. Keep Tilde webhook verification, ChatKit history, and server-side secrets intact. Help me deploy once to Vercel, import hello-world-agent/tilde.state.yaml with the deployed /api/hello-world endpoint, add the returned Tilde API key and webhook signing key to Vercel, and deploy to production. Finish by sending one test message through the Hello World UI ChatKit channel.
        </Prompt>
      </Step>
    </Steps>
  </Tab>

  <Tab title="For humans">
    <Steps>
      <Step title="Clone and install">
        You need Node.js 22 or newer, pnpm 10, a Tilde account, an OpenAI API key, and a Vercel account.

        ```bash
        git clone https://github.com/trytilde/examples.git
        cd examples/hello-world-agent
        pnpm install
        cp .env.example .env.local
        ```
      </Step>

      <Step title="Review the agent endpoint">
        The example contains this complete route at [`app/api/hello-world/route.ts`](https://github.com/trytilde/examples/blob/main/hello-world-agent/app/api/hello-world/route.ts):

        ```typescript app/api/hello-world/route.ts
        import { openai } from "@ai-sdk/openai";
        import {
          chatKitEndpoint,
          convertToAiSdkMessages,
          createClient,
        } from "@trytilde/harness-sdk-vercel-ai-node";
        import {
          consumeStream,
          convertToModelMessages,
          streamText,
        } from "ai";

        export const maxDuration = 60;

        function requiredEnv(name: string): string {
          const value = process.env[name]?.trim();
          if (!value) throw new Error(`${name} is required`);
          return value;
        }

        function createAgentHandler() {
          const tilde = createClient({
            apiKey: requiredEnv("TILDE_API_KEY"),
            baseUrl: process.env.TILDE_BASE_URL ?? "https://api.trytilde.ai",
            orgId: requiredEnv("TILDE_ORG_ID"),
            orgSubdomain: false,
            teamId: requiredEnv("TILDE_TEAM_ID"),
          });

          return chatKitEndpoint({
            client: tilde,
            webhookSigningKey: requiredEnv("TILDE_WEBHOOK_SIGNING_KEY"),
            requestTimeoutMs: 55_000,
            async handler(request, context) {
              const history = await context.session.history();
              const messages = await convertToAiSdkMessages({
                messages: [...history.items, ...context.messages],
                chatkit: context.chatkit,
              });
              const result = streamText({
                abortSignal: request.signal,
                messages: await convertToModelMessages(messages),
                model: openai(process.env.OPENAI_MODEL ?? "gpt-5.4"),
                system: "You are a helpful assistant. Keep your answers concise.",
              });

              return result.toUIMessageStreamResponse({
                consumeSseStream: consumeStream,
                originalMessages: messages,
              });
            },
          });
        }

        export async function POST(request: Request) {
          return createAgentHandler()(request);
        }
        ```

        Change the `system` instruction to change what your agent does. Keep the signed `chatKitEndpoint` wrapper and ChatKit history conversion.
      </Step>

      <Step title="Create a public endpoint">
        Deploy once to get a public URL. The route loads secrets only when Tilde invokes it, so this initial build does not require the environment variables yet.

        ```bash
        vercel deploy
        ```

        Your endpoint is the deployment URL plus `/api/hello-world`.
      </Step>

      <Step title="Create the Tilde resources">
        Import the example's [`tilde.state.yaml`](https://github.com/trytilde/examples/blob/main/hello-world-agent/tilde.state.yaml). Enter your endpoint when asked for `HELLO_WORLD_CHATKIT_ENDPOINT_URL`.

        <Card title="Deploy with Tilde" icon="rocket" href="https://api.trytilde.ai/deploy?repository-url=https%3A%2F%2Fgithub.com%2Ftrytilde%2Fexamples&state-path=hello-world-agent%2Ftilde.state.yaml" horizontal>
          Create the Hello World agent and its Vercel UI ChatKit channel.
        </Card>

        Save the one-time `api_key` and `webhook_signing_key` outputs from `chatkit/agent/hello-world`.
      </Step>

      <Step title="Configure the environment">
        Set these values in `.env.local` and in your Vercel project. Keep API and signing keys server-side.

        ```dotenv .env.local
        OPENAI_API_KEY=
        OPENAI_MODEL=gpt-5.4

        TILDE_API_KEY=
        TILDE_BASE_URL=https://api.trytilde.ai
        TILDE_ORG_ID=
        TILDE_TEAM_ID=
        TILDE_WEBHOOK_SIGNING_KEY=
        ```
      </Step>

      <Step title="Deploy and test">
        Deploy with the configured environment.

        ```bash
        vercel deploy --prod
        ```

        If the hostname changed, update the Tilde agent to the production `/api/hello-world` endpoint. Open **ChatKit**, select **Hello World UI**, and send:

        ```text
        Say hello in one sentence.
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>

For local development, run `pnpm dev` and expose port 3000 through a public HTTPS tunnel. Point the Tilde agent to the tunnel URL plus `/api/hello-world` while you test.
