## Popular Linq tools

- **Send a Linq message** — Send to recipients without choosing a from line. This is the recommended Linq path because it reuses healthy chats and load-balances/fails over across the account's line pool.
- **Send to an existing Linq chat** — Send a message in an existing Linq chat after checking its current health status. A 2024 opt-out response is terminal and must not be retried.
