## Popular Tilde Pay tools

- **get_tilde_pay_balances** — Refresh and return Tilde Pay balances.
- **get_tilde_pay_bank_deposit_information** — Refresh and return Tilde Pay bank deposit information.
- **get_tilde_pay_usdc_deposit_information** — Return USDC deposit information for Tilde Pay.
- **wait_until_tilde_pay_balance** — Wait until the cached Tilde Pay balance reaches a minimum amount.
- **list_transaction_history** — Return cached wallet transaction history without scanning the chain.
- **refresh_transaction_history** — Scan the chain and upsert cached wallet transaction history.
- **make_payment_x402** — Make an x402 payment from Tilde Pay.
- **make_payment_mpp** — Make an MPP payment from Tilde Pay.

## Connect Tilde Pay to an AI agent

Add Tilde Pay from the [Tilde dashboard](https://api.trytilde.ai/tools/available-tool-providers), then enable the tools your agent needs on an MCP server. [Learn how tools work in Tilde](/tools).
