## Popular Tilde Skill Registry tools

- **list_skills** — List skill names, descriptions, and versions in this bound registry.
- **search_skills** — Search this bound skill registry and return concise summaries before reading full skill content.
- **read_skill_description** — Read one skill description from this bound registry.
- **read_skill** — Read full content for one skill from this bound registry after progressive discovery.
