## Popular Google Calendar tools

- **Create a calendar event** — Create a calendar event with attendees, location, description, and optional Google Meet link
- **Search calendar events** — Search events by text query within a time range
- **List upcoming events** — List upcoming events on a calendar. Defaults to next 7 days.
- **Find free time slots** — Find available time slots across calendars within a date range
- **Update a calendar event** — Update an existing calendar event
- **Delete a calendar event** — Delete a calendar event
- **RSVP to a calendar event** — Respond to a calendar event invitation
- **List calendars** — List all calendars the user has access to
- **Get current date and time** — Get current date and time. Essential for relative scheduling since agents have no clock.
