## Popular Tavily tools

- **Search the web** — Run a Tavily web search and return ranked results, optional answers, images, raw content, and usage.
- **Extract web content** — Extract cleaned content from one or more URLs with Tavily Extract.
- **Crawl a website** — Crawl a website from a root URL with configurable depth, breadth, path/domain selection, and extraction options.
- **Map a website** — Map a website structure from a root URL and return discovered URLs.
- **Research a topic** — Create a Tavily research task and poll until completion, returning the synthesized content.
- **Get usage** — Return usage information for the Tavily API key.

Add Tavily from the [Tilde dashboard](https://api.trytilde.ai/tools/available-tool-providers), then enable the tools your agent needs on an MCP server. [Learn how tools work in Tilde](/tools).
